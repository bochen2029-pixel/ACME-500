# ACME-500 — read this first

ACME-500 is a virtual enterprise of 500 knowledge workers and its automation in one C++17 binary: a firm with planted truth, a resident with a field, a gate and a ladder, two graders with disjoint support, and an oracle battery where every oracle carries a lie. It tests the instrument, never a business. `docs/ARCHITECTURE_v4.md` (version 4.1) is the standing design since the operator's confirmation on 2026-09-15 — a superset whose Part II is v3 verbatim, and v2 verbatim inside that, so every §-reference still holds (`docs/DESIGN.md` is v1's, kept as the receipt of tag `v1-step-A`); `receipts/` holds every run with its numbers, and each step's receipt names what moved and what was not done.

**Rehydration:** a new session, a compaction or a context cut starts by reading `docs/HANDOFF_MAINLINE_2026-09-15.md` (what this is, where everything is, what is true now, the rules, how to run it, what is next). The whole acceptance run is `tools/run_step.sh <STAGE> [<PREV>]` under WSL; a quick build is `tools/build_wsl.sh`. `docs/ARCHITECTURE_v4.md` is the standing spec (its Part I §24–§41 adds the fifth world, lanes, the constitution in code, the ladder v2 and the calibration harness, counterparty planes and installments, tenancy, lineage, models behind lanes, compile-out, the account, the standard, O31–O58 and kills 20–27; §39.2 is the order as confirmed: E3 → F0 → F1a → F1b → E1′ → E2 → G0/G → H → H2 → I, with G0 allowed to start any time); v3's §18–§23 and v2's §0–§17 stand inside it.

- A lie arm counts only when the lied-to oracle is seen to catch its lie. A nonzero exit for an unrelated reason is not a caught lie.
- Never report a process as running without its PID and CPU time against wall time. Never report green without the lie.
- The physics in `firm.h` and `world.h` is not under review. Do not tune a constant to pass an oracle.
